# ✅ Todo App

A todo app built with vanilla JS. Users sign up with a username, then land on their personal dashboard where they can manage their todos. Built my own way — no tutorials copied.

🔗 **Live:** https://nb-todo.vercel.app/

## Features
- Sign-up screen (username + details)
- Personal dashboard after sign-up
- Add, complete, and delete todos
- Data saved so it's still there on refresh

## Flow
1. User lands on sign-up page
2. Enters username + details
3. Redirected to dashboard
4. Manages todos from there

## Run it
```bash
git clone https://github.com/nhlamulobaloyi006/nb-todo-app.git
cd nb-todo-app
```
Open `index.html`. Done.

## Built with
HTML, CSS, vanilla JS.

## What I learned
- Handling user input & form flow
- Multi-screen navigation (sign-up → dashboard)
- Saving data with localStorage
- Building things my own way instead of following tutorials
